# killer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS terminal UI that lists running apps and quits or force quits the ones you pick, without ever quitting Finder, the launching terminal, or macOS system processes.

**Architecture:** One Rust binary. `apps.rs` is the only file that calls AppKit (`NSWorkspace`, `NSRunningApplication`) or `libc`. `model.rs` holds state, key handling, and the pure logic covered by tests. `ui.rs` draws a frame from the model with Ratatui. `main.rs` runs the event loop.

**Tech Stack:** Rust (stable, 1.100 tested), Ratatui 0.30, objc2-app-kit 0.3, objc2-foundation 0.3, libc 0.2.

**Spec:** `docs/specs/2026-11-19-killer-design.md`

## Global Constraints

- macOS only. Every command runs from `/Users/ian/Documents/killer`.
- If `cargo` isn't found, run `. "$HOME/.cargo/env"` first.
- `objc2-app-kit` features: `std`, `libc`, `NSRunningApplication`, `NSWorkspace`. Without `libc`, `processIdentifier()` and `runningApplicationWithProcessIdentifier()` don't exist.
- `objc2-foundation` features: `std`, `NSRunLoop`, `NSDate`, `NSString`, `NSArray`, `NSEnumerator`.
- No other dependencies. Ratatui re-exports crossterm as `ratatui::crossterm`, so don't add crossterm separately.
- Only `apps.rs` may contain `unsafe` or call AppKit.
- Every pid passed to `apps::quit` or `apps::force_quit` must come from `model::quit_targets`.
- Colors: only the 16 ANSI colors (`Color::Cyan`, `Color::Red`, `Color::Yellow`) plus `dim`, `bold`, and `reversed`. No RGB.
- Default exclusions: `com.apple.finder`. User file: `~/.config/killer/exclude`, one bundle ID per line, `#` comments, added to the defaults.
- Timings: key poll 250ms, refresh 2s, toast 3s, "still open" after 10s.

```rust
use objc2_app_kit::{NSApplicationActivationPolicy, NSRunningApplication, NSWorkspace};
use objc2_foundation::{NSDate, NSRunLoop};

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Kind {
    Regular,
    MenuBar,
    Helper,
}

#[derive(Clone, Debug, PartialEq)]
pub struct App {
    pub name: String,
    pub bundle_id: String,
    pub pid: i32,
    pub kind: Kind,
    pub memory_bytes: Option<u64>,
}

// A CLI has no Cocoa run loop, so NSWorkspace never sees launch/quit
// notifications unless we spin the loop ourselves.
fn pump_run_loop() {
    let until = NSDate::dateWithTimeIntervalSinceNow(0.01);
    NSRunLoop::currentRunLoop().runUntilDate(&until);
}

pub fn list() -> Vec<App> {
    pump_run_loop();
    NSWorkspace::sharedWorkspace()
        .runningApplications()
        .iter()
        .filter_map(|app| {
            let pid = app.processIdentifier();
            if pid <= 0 {
                return None;
            }
            let policy = app.activationPolicy();
            let kind = if policy == NSApplicationActivationPolicy::Regular {
                Kind::Regular
            } else if policy == NSApplicationActivationPolicy::Accessory {
                Kind::MenuBar
            } else {
                Kind::Helper
            };
            Some(App {
                name: app.localizedName().map(|s| s.to_string()).unwrap_or_default(),
                bundle_id: app.bundleIdentifier().map(|s| s.to_string()).unwrap_or_default(),
                pid,
                kind,
                memory_bytes: memory_bytes(pid),
            })
        })
        .collect()
}

// Same number Activity Monitor shows as "Memory".
fn memory_bytes(pid: i32) -> Option<u64> {
    let mut info: libc::rusage_info_v2 = unsafe { std::mem::zeroed() };
    let rc = unsafe {
        libc::proc_pid_rusage(pid, libc::RUSAGE_INFO_V2, &mut info as *mut _ as *mut _)
    };
    (rc == 0).then_some(info.ri_phys_footprint)
}

pub fn frontmost_pid() -> Option<i32> {
    pump_run_loop();
    NSWorkspace::sharedWorkspace()
        .frontmostApplication()
        .map(|app| app.processIdentifier())
}

pub fn quit(pid: i32) -> bool {
    NSRunningApplication::runningApplicationWithProcessIdentifier(pid)
        .is_some_and(|app| app.terminate())
}

pub fn force_quit(pid: i32) -> bool {
    NSRunningApplication::runningApplicationWithProcessIdentifier(pid)
        .is_some_and(|app| app.forceTerminate())
}
```

```rust
use std::path::PathBuf;

pub const DEFAULT_EXCLUDED: &[&str] = &["com.apple.finder"];

pub fn parse(text: &str) -> Vec<String> {
    text.lines()
        .map(str::trim)
        .filter(|line| !line.is_empty() && !line.starts_with('#'))
        .map(String::from)
        .collect()
}

fn path() -> Option<PathBuf> {
    std::env::var_os("HOME").map(|home| PathBuf::from(home).join(".config/killer/exclude"))
}

/// The exclusion list (defaults plus the user's file), and a warning for the UI if the file couldn't be read.
pub fn load() -> (Vec<String>, Option<String>) {
    let mut excluded: Vec<String> = DEFAULT_EXCLUDED.iter().map(|s| s.to_string()).collect();
    let Some(path) = path() else {
        return (excluded, None);
    };
    match std::fs::read_to_string(&path) {
        Ok(text) => excluded.extend(parse(&text)),
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => {}
        Err(e) => return (excluded, Some(format!("Couldn't read {}: {e}", path.display()))),
    }
    (excluded, None)
}
```

```rust
use std::collections::HashSet;

use crate::apps::{App, Kind};

#[derive(Clone, Copy, Debug, PartialEq)]
pub enum Sort {
    Memory,
    Name,
}

pub fn is_protected(app: &App, excluded: &[String], terminal_pid: i32) -> bool {
    app.pid == terminal_pid
        || excluded.iter().any(|b| *b == app.bundle_id)
        // Background Apple processes include loginwindow and Dock: quitting them logs you out or breaks the desktop.
        || (app.kind != Kind::Regular
            && (app.bundle_id.is_empty() || app.bundle_id.starts_with("com.apple.")))
}

pub fn visible<'a>(apps: &'a [App], show_bg: bool, filter: &str, sort: Sort) -> Vec<&'a App> {
    let needle = filter.to_lowercase();
    let mut out: Vec<&App> = apps
        .iter()
        .filter(|a| show_bg || a.kind == Kind::Regular)
        .filter(|a| a.name.to_lowercase().contains(&needle))
        .collect();
    match sort {
        // None < Some, so comparing b to a puts unknown memory last.
        Sort::Memory => out.sort_by(|a, b| {
            b.memory_bytes.cmp(&a.memory_bytes).then_with(|| a.name.cmp(&b.name))
        }),
        Sort::Name => out.sort_by_key(|a| a.name.to_lowercase()),
    }
    out
}

/// The only source of pids passed to apps::quit / apps::force_quit.
pub fn quit_targets(
    apps: &[App],
    selected: &HashSet<i32>,
    cursor_pid: Option<i32>,
    excluded: &[String],
    terminal_pid: i32,
) -> Vec<App> {
    let wanted: HashSet<i32> = if selected.is_empty() {
        cursor_pid.into_iter().collect()
    } else {
        selected.clone()
    };
    apps.iter()
        .filter(|a| wanted.contains(&a.pid) && !is_protected(a, excluded, terminal_pid))
        .cloned()
        .collect()
}
```

```rust
fn names(apps: &[App]) -> String {
    apps.iter().map(|a| a.name.as_str()).collect::<Vec<_>>().join(", ")
}

pub struct Model {
    pub apps: Vec<App>,
    pub selected: HashSet<i32>,
    pub list: ListState,
    pub filter: String,
    pub filtering: bool,
    pub show_bg: bool,
    pub sort: Sort,
    pub pending: HashMap<i32, Instant>,
    pub toast: Option<(String, Instant)>,
    pub confirm: Option<Vec<App>>,
    pub help: bool,
    pub excluded: Vec<String>,
    pub terminal_pid: i32,
    refreshed: Instant,
}

impl Model {
    pub fn new(excluded: Vec<String>, terminal_pid: i32) -> Self {
        Self {
            apps: Vec::new(),
            selected: HashSet::new(),
            list: ListState::default(),
            filter: String::new(),
            filtering: false,
            show_bg: false,
            sort: Sort::Memory,
            pending: HashMap::new(),
            toast: None,
            confirm: None,
            help: false,
            excluded,
            terminal_pid,
            refreshed: Instant::now(),
        }
    }

    pub fn visible(&self) -> Vec<&App> {
        visible(&self.apps, self.show_bg, &self.filter, self.sort)
    }

    pub fn protected(&self, app: &App) -> bool {
        is_protected(app, &self.excluded, self.terminal_pid)
    }

    fn cursor_pid(&self) -> Option<i32> {
        let i = self.list.selected()?;
        self.visible().get(i).map(|a| a.pid)
    }

    pub fn set_toast(&mut self, msg: impl Into<String>) {
        self.toast = Some((msg.into(), Instant::now()));
    }

    fn clamp_cursor(&mut self) {
        let n = self.visible().len();
        let i = if n == 0 { None } else { Some(self.list.selected().unwrap_or(0).min(n - 1)) };
        self.list.select(i);
    }

    pub fn refresh(&mut self) {
        self.apply_refresh(apps::list());
    }

    /// Split from refresh() so tests can feed a fake app list.
    pub fn apply_refresh(&mut self, apps: Vec<App>) {
        self.apps = apps;
        self.refreshed = Instant::now();
        let alive: HashSet<i32> = self.apps.iter().map(|a| a.pid).collect();
        self.selected.retain(|pid| alive.contains(pid));
        self.pending.retain(|pid, _| alive.contains(pid));

        let stuck: Vec<App> = self
            .apps
            .iter()
            .filter(|a| self.pending.get(&a.pid).is_some_and(|t| t.elapsed() >= QUIT_TIMEOUT))
            .cloned()
            .collect();
        if !stuck.is_empty() {
            for a in &stuck {
                self.pending.remove(&a.pid);
            }
            self.set_toast(format!("{} still open (save dialog?)", names(&stuck)));
        }
        self.clamp_cursor();
    }

    pub fn tick(&mut self) {
        if self.refreshed.elapsed() >= REFRESH {
            self.refresh();
        }
        if self.toast.as_ref().is_some_and(|(_, t)| t.elapsed() >= TOAST_TTL) {
            self.toast = None;
        }
    }

    pub fn targets(&self) -> Vec<App> {
        quit_targets(&self.apps, &self.selected, self.cursor_pid(), &self.excluded, self.terminal_pid)
    }

    fn send_quit(&mut self, targets: Vec<App>, force: bool) {
        let mut failed = Vec::new();
        let mut sent = Vec::new();
        for a in targets {
            let ok = if force { apps::force_quit(a.pid) } else { apps::quit(a.pid) };
            if ok {
                self.pending.insert(a.pid, Instant::now());
                sent.push(a);
            } else {
                failed.push(a);
            }
        }
        self.selected.clear();
        if failed.is_empty() {
            self.set_toast(format!("✓ Quitting {}", names(&sent)));
        } else {
            self.set_toast(format!("Couldn't quit {}", names(&failed)));
        }
        self.refresh();
    }

    pub fn toggle_cursor(&mut self) {
        let Some(pid) = self.cursor_pid() else { return };
        let Some(app) = self.apps.iter().find(|a| a.pid == pid).cloned() else { return };
        if self.protected(&app) {
            self.set_toast(format!("{} is protected", app.name));
        } else if !self.selected.remove(&pid) {
            self.selected.insert(pid);
        }
    }

    pub fn toggle_all(&mut self) {
        let pids: Vec<i32> = self
            .visible()
            .into_iter()
            .filter(|a| !self.protected(a))
            .map(|a| a.pid)
            .collect();
        if pids.iter().all(|p| self.selected.contains(p)) {
            for p in &pids {
                self.selected.remove(p);
            }
        } else {
            self.selected.extend(pids);
        }
    }

    /// Returns false when the app should exit.
    pub fn on_key(&mut self, key: KeyEvent) -> bool {
        if key.code == KeyCode::Char('c') && key.modifiers.contains(KeyModifiers::CONTROL) {
            return false;
        }
        if let Some(targets) = self.confirm.take() {
            if key.code == KeyCode::Char('y') {
                self.send_quit(targets, true);
            }
            return true;
        }
        if self.help {
            self.help = false;
            return true;
        }
        if self.filtering {
            match key.code {
                KeyCode::Esc => {
                    self.filter.clear();
                    self.filtering = false;
                }
                KeyCode::Enter => self.filtering = false,
                KeyCode::Backspace => {
                    self.filter.pop();
                }
                KeyCode::Up => self.list.select_previous(),
                KeyCode::Down => self.list.select_next(),
                KeyCode::Char(c) => self.filter.push(c),
                _ => {}
            }
            self.clamp_cursor();
            return true;
        }
        match key.code {
            KeyCode::Esc if !self.filter.is_empty() => self.filter.clear(),
            KeyCode::Esc => return false,
            KeyCode::Up | KeyCode::Char('k') => self.list.select_previous(),
            KeyCode::Down | KeyCode::Char('j') => self.list.select_next(),
            KeyCode::Char(' ') => self.toggle_cursor(),
            KeyCode::Char('a') => self.toggle_all(),
            KeyCode::Enter => match self.targets() {
                t if t.is_empty() => self.set_toast("Nothing to quit"),
                t => self.send_quit(t, false),
            },
            KeyCode::Char('Q') => match self.targets() {
                t if t.is_empty() => self.set_toast("Nothing to quit"),
                t => self.confirm = Some(t),
            },
            KeyCode::Char('/') => self.filtering = true,
            KeyCode::Char('b') => self.show_bg = !self.show_bg,
            KeyCode::Char('s') => {
                self.sort = match self.sort {
                    Sort::Memory => Sort::Name,
                    Sort::Name => Sort::Memory,
                }
            }
            KeyCode::Char('?') => self.help = true,
            _ => {}
        }
        self.clamp_cursor();
        true
    }
}
```

```rust
use ratatui::style::{Color, Style, Stylize};
use ratatui::text::{Line, Span};
use ratatui::widgets::{Block, BorderType, Clear, List, ListItem, Paragraph};
use ratatui::Frame;

use crate::apps::{App, Kind};
use crate::model::{Model, Sort};

const NAME_WIDTH: usize = 22;
const BAR_WIDTH: usize = 12;
const ACCENT: Color = Color::Cyan;

pub fn fmt_bytes(bytes: u64) -> String {
    const MB: f64 = 1024.0 * 1024.0;
    const GB: f64 = MB * 1024.0;
    let b = bytes as f64;
    if b >= GB { format!("{:.1} GB", b / GB) } else { format!("{:.0} MB", b / MB) }
}

pub fn bar(frac: f64, width: usize) -> String {
    const PARTS: [&str; 8] = ["", "▏", "▎", "▍", "▌", "▋", "▊", "▉"];
    let eighths = (frac.clamp(0.0, 1.0) * (width * 8) as f64).round() as usize;
    let mut s = "█".repeat(eighths / 8);
    s.push_str(PARTS[eighths % 8]);
    s
}

fn badge(m: &Model, a: &App) -> &'static str {
    if m.pending.contains_key(&a.pid) {
        "quitting…"
    } else if a.pid == m.terminal_pid {
        "this terminal"
    } else if m.excluded.contains(&a.bundle_id) {
        "excluded"
    } else if m.protected(a) {
        "system"
    } else {
        match a.kind {
            Kind::Regular => "",
            Kind::MenuBar => "menu bar",
            Kind::Helper => "helper",
        }
    }
}

fn row(m: &Model, a: &App, max_mem: u64) -> ListItem<'static> {
    let protected = m.protected(a);
    let selected = m.selected.contains(&a.pid);
    let marker = if protected {
        Span::raw("🔒")
    } else if selected {
        Span::styled("● ", Style::new().fg(ACCENT))
    } else {
        Span::raw("○ ").dim()
    };
    let name: String = a.name.chars().take(NAME_WIDTH).collect();
    let mem = a.memory_bytes.map(fmt_bytes).unwrap_or_else(|| "—".into());
    let frac = a.memory_bytes.unwrap_or(0) as f64 / max_mem as f64;
    let badge = badge(m, a);
    let line = Line::from(vec![
        marker,
        Span::raw(format!(" {name:<NAME_WIDTH$} ")),
        Span::styled(format!("{:<BAR_WIDTH$}", bar(frac, BAR_WIDTH)), Style::new().fg(ACCENT)),
        Span::raw(format!(" {mem:>8}  ")),
        if badge == "quitting…" { Span::raw(badge).fg(Color::Yellow) } else { Span::raw(badge).dim() },
    ]);
    ListItem::new(if protected { line.dim() } else { line })
}

fn centered(area: Rect, width: u16, height: u16) -> Rect {
    let [area] = Layout::horizontal([Constraint::Length(width)]).flex(Flex::Center).areas(area);
    let [area] = Layout::vertical([Constraint::Length(height)]).flex(Flex::Center).areas(area);
    area
}

fn modal(f: &mut Frame, title: &str, color: Color, lines: Vec<Line>) {
    let width = lines.iter().map(|l| l.width()).max().unwrap_or(0) as u16 + 4;
    let area = centered(f.area(), width, lines.len() as u16 + 2);
    let block = Block::bordered()
        .border_type(BorderType::Rounded)
        .border_style(Style::new().fg(color))
        .title(format!(" {title} "));
    f.render_widget(Clear, area);
    f.render_widget(Paragraph::new(lines).block(block), area);
}

pub fn draw(f: &mut Frame, m: &mut Model) {
    let block = Block::bordered()
        .border_type(BorderType::Rounded)
        .title(" killer ".bold().fg(ACCENT))
        .title_bottom(
            Line::from(" space select  a all  ⏎ quit  ⇧Q force  / filter  b background  s sort  ? help ")
                .dim(),
        );
    let inner = block.inner(f.area());
    f.render_widget(block, f.area());
    let [header, rule1, body, rule2, footer] = Layout::vertical([
        Constraint::Length(1),
        Constraint::Length(1),
        Constraint::Fill(1),
        Constraint::Length(1),
        Constraint::Length(1),
    ])
    .areas(inner);

    // Header: filter on the left, selection summary on the right.
    let filter = if m.filtering {
        Line::from(vec![Span::raw(" / ").fg(ACCENT), Span::raw(format!("{}▏", m.filter))])
    } else if !m.filter.is_empty() {
        Line::from(vec![Span::raw(" / ").fg(ACCENT), Span::raw(m.filter.clone())])
    } else {
        Line::from(" / filter").dim()
    };
    f.render_widget(Paragraph::new(filter), header);
    let total: u64 = m
        .apps
        .iter()
        .filter(|a| m.selected.contains(&a.pid))
        .filter_map(|a| a.memory_bytes)
        .sum();
    let sort = if m.sort == Sort::Memory { "by memory" } else { "by name" };
    let bg = if m.show_bg { " · background on" } else { "" };
    let summary = format!("{} selected · {} · {sort}{bg} ", m.selected.len(), fmt_bytes(total));
    f.render_widget(Paragraph::new(summary).alignment(Alignment::Right), header);

    let rule = Paragraph::new("─".repeat(inner.width as usize)).dim();
    f.render_widget(rule.clone(), rule1);
    f.render_widget(rule, rule2);

    // App list. Build owned rows first so the borrow of m ends before rendering with &mut m.list.
    let visible = m.visible();
    let max_mem = visible.iter().filter_map(|a| a.memory_bytes).max().unwrap_or(1).max(1);
    let items: Vec<ListItem> = visible.iter().map(|a| row(m, a, max_mem)).collect();
    if items.is_empty() {
        f.render_widget(Paragraph::new("No apps match").dim().alignment(Alignment::Center), body);
    } else {
        let list = List::new(items).highlight_style(Style::new().reversed()).highlight_symbol("▌");
        f.render_stateful_widget(list, body, &mut m.list);
    }

    if let Some((msg, _)) = &m.toast {
        f.render_widget(Paragraph::new(format!(" {msg}")).bold(), footer);
    }

    if let Some(targets) = &m.confirm {
        let names: Vec<&str> = targets.iter().map(|a| a.name.as_str()).collect();
        modal(f, "Force quit", Color::Red, vec![
            Line::from(format!("Force quit {} app(s)? Unsaved work is lost.", targets.len())),
            Line::from(names.join(", ")).dim(),
            Line::from(""),
            Line::from(vec![Span::raw("y").bold().fg(Color::Red), Span::raw(" force quit   any other key cancels")]),
        ]);
    } else if m.help {
        let keys = [
            ("↑ ↓  k j", "move"),
            ("space", "select / unselect"),
            ("a", "select all (again to clear)"),
            ("⏎", "quit selection, or cursor row"),

            ("/", "filter by name, esc clears"),
            ("b", "show background apps"),
            ("s", "sort by memory / name"),

            .iter()

            .collect();
        modal(f, "Keys", ACCENT, lines);
    }
}
```

```rust
mod apps;
mod config;
mod model;
mod ui;

use std::time::Duration;

use ratatui::crossterm::event::{self, Event, KeyEventKind};
use ratatui::DefaultTerminal;

use model::Model;

fn main() -> std::io::Result<()> {
    let (excluded, warning) = config::load();
    // Read before the UI starts, while the terminal that launched us is still frontmost.
    let terminal_pid = apps::frontmost_pid().unwrap_or(-1);
    let mut m = Model::new(excluded, terminal_pid);
    m.refresh();
    if let Some(w) = warning {
        m.set_toast(w);
    }
    ratatui::run(|terminal| run(terminal, &mut m))
}

fn run(terminal: &mut DefaultTerminal, m: &mut Model) -> std::io::Result<()> {
    loop {
        terminal.draw(|f| ui::draw(f, m))?;
        if event::poll(Duration::from_millis(250))? {
            if let Event::Key(key) = event::read()? {
                if key.kind == KeyEventKind::Press && !m.on_key(key) {
                    return Ok(());
                }
            }
        }
        m.tick();
    }
}
```
