Apps and ports

kat opens on your apps. Press tab for the ports. Both work the same way: move, select, press ⏎.

Apps

Clear out the Dock

kat asks each app to quit politely, so it can still offer to save. Apps are sorted by memory, using the same number Activity Monitor shows.

Find whatever's on that port

The Ports tab shows every listening socket, the project folder it was started from, and the process behind it. No more lsof -i and copying pids around.

● :3000 next dev ~/code/shop ○ :5173 vite ~/code/blog ○ :8765 http.server ~/Downloads
locked

Some things stay put

Finder, the terminal you launched kat from, and macOS background apps like loginwindow are locked. So are Docker and OrbStack ports. Add your own with one bundle ID per line.

# ~/.config/kat/exclude com.1password.1password com.apple.Music

Get kat

macOS only, Apple silicon and Intel. Update with brew upgrade. In iTerm2 and WezTerm, rows show real app icons.

$ brew install pregnantboy/tap/kat
